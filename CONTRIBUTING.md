# Как внести вклад в Alva

Спасибо за интерес к проекту. Ниже — короткий порядок работы.

## Сборка и тесты

```powershell
dotnet restore Alva.slnx
dotnet build Alva.slnx -c Release
dotnet test Alva.slnx -c Release
```

Требуется .NET SDK 10.0.401 (см. `global.json`). Сборка не должна давать предупреждений,
все тесты (`tests/`) должны проходить.

## Структура

`Alva.slnx` объединяет проекты `src/` и тесты `tests/`. Слои: домен (`Alva.Domain`),
инфраструктура (`Alva.Infrastructure`), контракты (`Alva.Contracts`), API (`Alva.Api`)
и клиент (`Alva.Client.UI` + оболочки `Alva.Client` и `Alva.Client.Demo`).

## Правила

- Общая библиотека UI (`Alva.Client.UI`) обслуживает и прод, и демо: различия — только
  в реализации `IApiService`.
- Компоненты и токены берутся из Flare; собственный CSS и JS держатся минимальными.
- Тесты пишутся на поведение (bUnit для UI, интеграционные тесты для API и данных).
- Сообщения и интерфейс — на русском.
- Комментарии объясняют «почему», а не пересказывают код.

## Pull request

1. Ветка от `main`.
2. Сборка без предупреждений и зелёные тесты.
3. В описании — что изменилось и как проверено.

## Сообщения об ошибках

Приложите шаги воспроизведения, ожидаемое и фактическое поведение, режим
(демо или сервер), версию браузера и, если возможно, журнал.
